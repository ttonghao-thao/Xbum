# 自动整理相册

2026-11-15 用户确认：上传后的内容由系统自动整理，首页三个入口进入独立相册；手动配置仅作可选覆盖。该决定替换原规格 F04/F05 中成长线必须先手动启用的前置条件。

根因：旧首页从每日播放列表找一个 scene_type，命中只打开单张，未命中「往年今日」打开整个照片库；旅行依赖 confirmed，成长依赖 growth_enabled。播放列表有数量限制、每张只有一个场景，不能作为完整相册目录。

当日实机复查又发现：仅查询 family 把上传者本人私密照片也排除在整理浏览外；VLM 输出字段可选并自动补默认值，导致不完整回答以 confidence=0 / other 记录为成功；旧任务没有输出契约升级补偿。修正后分别处理本人整理权限、严格模型契约和历史自动补处理，不能把“页面有入口”当作历史数据已经可用。

## 归类规则

| 相册 | 自动规则 | 人工覆盖 |
|---|---|---|
| 往年今日 | 按家庭时区解释可信 taken_at；包含往年同月同日及前后 3 天，同日与邻近日期并存；邻近标注「这几天」，按原年份分组；跨年不把昨日误称一年前 | 人工更正拍摄日期立即生效。未知时间与上传时间不充作拍摄日期 |
| 慢慢长大 | 从已有 VLM scene_tags/objects/visible_activity/caption 中识别儿童/婴幼儿画面；已登记家庭人物跨月记录，或有成长画面支撑的跨月相似人物候选也纳入；按拍摄年月排序，未知日期单列 | 人物可设 auto/include/exclude。存在 include 时严格采用指定人物集合；指定人物没有照片时保持空相册；exclude 关联照片不会因模型重跑重新纳入。可恢复 auto |
| 一起走过 | VLM travel/outing 及有对应内容支撑的自动事件；未知时间仍可作为候选，不编造活动日期或城市；有事件时按事件分组、内部按时间排序 | 锁定/确认事件类型优先；手动改为 daily/other 等立即排除，手动 travel/outing 纳入，不被模型重跑覆盖 |

VLM 分类仅使用 confidence ≥ 0.5 的已有结构化结果；这是工程候选阈值，不是准确率保证。否定画面描述与 uncertainties 不作为儿童证据。自动人物候选不表示同一孩子的身份已经确认，不生成姓名、亲属关系或「第一次」。人脸分析保持默认关闭，自动成长内容不依赖开启人脸；已有人工照片人物标记可继续使用。

集合允许交叉：同一张成长出游照片可同时属于成长和旅行，专属相册不受今日精选数量限制。API 仅做数据库读与轻量筛选，模型仍通过单 Worker 的子进程异步运行；完成后首页/相册每 5 秒更新，推荐通过已有去抖任务更新。人工变更立即反映到相册，并触发推荐更新。

三个相册默认用于本人整理浏览：当前家庭的 family，加上上传者本人的 private；排除 hidden/deleted，每次读取重检。私密缩略图仍通过 photo_access 验证，不向其他成员、跨家庭或 display 会话开放。`scope=family` 可显式只读家庭共享集合，推荐引擎继续采用该集合。个人整理不自动修改 visibility，不把私密内容加入家庭轮播、共享故事或家庭检索。首页无家庭播放列表时可从本人可见相册取封面，链接个人相册，不用私密封面引导相框播放。

照片库可用左上角复选框多选，或「选中本页我的照片」选取本页；「加入家庭共享」显示明确确认，只有确认后才 POST 批量 share。每批最多 200 张，仅上传者本人可共享，删除照片不可共享；整批先校验再变更，并记录审计。分页清除选择，后续上传默认值不变。共享/日期修改触发事件与推荐去抖更新，复用有效 VLM；人脸仅在家庭已授权时补跑对应步骤。

## 历史分析自动补偿

`VISION_CONTRACT_VERSION=2`：7 个原有 JSON 字段全部必填，caption 非空。Ollama 解码限制短数组和短描述；明确截断的结果和缺字段结果均失败，不补造置信度。模型权重版本与输出契约版本独立记录。

单 Worker 启动及每 60 秒扫描当前家庭未隐藏/未删除照片，按契约版本为旧结果、缺结果和历史失败补排 VLM。新上传与补偿采用相同 `photo:{id}:vlm:vision-{version}` 幂等键；已有在途任务和当前有效结果不重复入队。每个版本沿用有限重试，失败达到上限不会在每次扫描时重置尝试次数；页面显示失败数，任务页保留历史失败记录。暂停和 VLM 关闭时不补排。

分类规则本身是读取已有数据的轻量逻辑，修改日期窗口不需要重跑模型。本次升级改变的是模型输出完整性契约，因此旧版视觉结果自动补处理；无需重跑已经有效的 metadata/quality/embedding。完成后自动刷新分类与推荐；人工标题、日期、人物选择和锁定事件保持原值。

## 验证边界

分类/时间/覆盖回归使用合成图片及明确注入的结构化分析 fixture，覆盖异步模型→事件→相册→推荐的契约。浏览器使用独立数据库、真实 API/Worker；重模型关闭，验证入口、日期筛选、空态与人工覆盖。迁移对带人物/人脸/里程碑的旧 schema 副本升级，校验保留关联与原手动选择。
