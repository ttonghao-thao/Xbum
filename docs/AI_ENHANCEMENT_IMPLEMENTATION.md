## 同页照片影片

服务端基于完整相册选片，API 返回已授权序列与 revision。播放器只负责连续播放、控制和显示，分类/选片保留在后端。影片不受下方照片分页截断；下方可以切换精选与全部，全部集合不因影片张数缩减。零张、单张、分析等待和读取失败分别有真实状态。

播放器每 2 秒重新校验；API 出错时清空画面，不继续播旧清单。用户暂停不会被普通数据刷新强制恢复，离开页面清理定时器；页面转入后台暂停，返回后重新请求。照片影片本身静音，不需要等待 FFmpeg，也不受有声媒体 autoplay 限制；全屏被浏览器拒绝时保留页面内控制。

自动相册 `visible` 范围为本人 private + 已授权 family，hidden/deleted 排除；其他成员和 display 不能获得本人私密封面、计数或播放序列。家庭故事/搜索/相框仍仅使用 family。智能相册集合另采用“创建者可见、素材 family-only”的边界。

## 搜索、集合和文本来源

搜索先执行日期、人物、事件、地点、硬主题与排除条件，再用匹配文字及同版本向量排序。“全家”要求已确认家庭人物全部出现；不明确的关系或“上次”不对应确定事件时给出未知条件并保持空结果，不悄悄放宽。

OCR 文本和已确认口述转写是新增检索来源。OCR 保存识别文本、区域与 `apple-vision-text-1` 版本，人工校对独立保存，后续模型结果不覆盖。事件关联转写须其关联照片仍全部共享；不以一张仍共享的照片带出已撤回事件文字。

动态集合保存可重现的结构化/文字条件，禁用语义向量排序作为成员判断；以图搜图结果只能保存固定集合。人工加入/排除记录优先，暂时撤回共享不会删除人工覆盖记录，恢复共享后仍遵守。相册标题、封面、照片计数、存储 ID 与播放内容均按创建者和当前 family 资格重检。

## 故事、原声与人工优先

`story_compose` 在持久队列中选片，短/中/长分别最多 12/24/60 张，按日期组织章节。照片说明只取人工说明/标题或可信拍摄日期，在编排来源中记录 `caption_source`、照片 ID 与日期，可回到照片核对拍摄时间来源；不编造人物、城市或里程碑。`StoryPlan.expected_version` 阻止迟到任务覆盖人工修改；编辑过的故事另建精选版本，不自动重写原稿。

原声必须是已确认转写、非临时查询录音，且与故事当前照片/事件有关。绑定保存来源摘要；录音删除、转写变化、照片撤回或事件关联变化后，旧播放和导出不可访问。带原声的 MP4 对应画面会延长到录音时长；未绑定音轨仍导出静音视频。浏览器默认静音，用户可显式开启原声；家庭 display 使用故事专用受权音频端点。

## 后台资源与历史数据

`processing_status` 使用可用内存、可用磁盘及家庭时区的后台小时窗口。开始/结束小时相同代表全天；保留量默认内存 512MB、磁盘 1024MB。重型照片任务、OCR、故事编排和导出在资源不足或窗口外暂缓领取，基础服务继续可用；用户查询编码仍使用现有较高队列优先级。当前没有温度传感器、自动降频或运行任务抢占能力。

OCR 通过运行在模型子进程中的 Swift 调用系统 Vision，配置中文简体与英文，无独立下载权重，无运行时第三方请求。历史补齐只排缺失/过期的 OCR，使用版本幂等键和有限重试；不会无差别重跑 metadata/quality/embedding/VLM。原 VLM 严格契约及历史补偿继续保留。

## 验证与后续评估

新增回归覆盖权限隔离、跨分页取材、人工覆盖、硬条件/同框、集合撤权、OCR 校对、故事版本和原声失效。仅将 [TEST_REPORT.md](TEST_REPORT.md) 中实际执行的记录作为测试结论；合成图片/录音、测试 provider、真实模型冒烟、真实家庭准确率与硬件现场验证分别报告。
