## 明确未完成的现场验收与设计取舍

1. 尚缺至少 100 张授权、人工标注的真实家庭样本，因此不报告标签准确率、事件识别误报/漏报、人脸准确率或真实家庭推荐满意度。
2. 尚缺实体手机 HTTPS/证书/麦克风、中屏触控、实际 Mac 重启、物理断网和 3000 张真实 AI 长稳负载测试；本地模拟不能替代这些条件。
3. 服务器不可达时无法证明缓存照片未被撤权。当前选择 fail closed：外网断开但本地服务可达可正常使用；API 不可达则停止播放。原规格“断开 API 仍播缓存”和“即时撤权”不能同时保证，这一项是明确偏离，不能标为全通过。
4. MP4 为本地静音照片幻灯片，字幕位于照片下方、最多两行；长说明完整保存在故事 JSON 中，视频字幕显示空间有限。
5. 完整备份由文件权限保护，不做应用层加密；需配合加密磁盘。人脸模型/训练数据商业授权需独立审查。
6. 源代码与合成测试证据随仓库版本交付；用户家庭照片、数据库、原始分析正文、凭据、模型权重和备份均排除在 Git 提交之外。远端交付版本以 main 的实际提交记录为准。
